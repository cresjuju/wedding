# 방명록 연동 (구글 스프레드시트)

1. [Google Sheets](https://sheets.new)에서 새 스프레드시트를 만든다. (이름 예: `청첩장 방명록`)
2. 메뉴 **확장 프로그램 → Apps Script** 를 연다.
3. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 를 통째로 붙여넣은 뒤 저장(Ctrl+S).
4. 오른쪽 위 **배포 → 새 배포**
   - 유형 선택(톱니바퀴) → **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** 클릭
5. 권한 승인 창이 뜨면 본인 계정 선택 →
   "Google에서 확인하지 않은 앱" 화면에서 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음) → 허용**
   (본인이 만든 스크립트라 괜찮습니다)
6. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 을 복사해서
   `index.html` 의 방명록 섹션 `data-endpoint=""` 안에 붙여넣고 커밋/푸시.

## 관리자 삭제 (선택)
Apps Script 왼쪽 **프로젝트 설정(톱니바퀴) → 스크립트 속성 → 속성 추가**
`ADMIN_PASSWORD` = 원하는 비밀번호. 이 비밀번호로 아무 글이나 삭제할 수 있다.

## 코드를 수정했을 때
**배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포**
("새 배포"를 하면 URL 이 바뀌므로 주의)

## 시트에서 직접 관리
- 글 숨기기: 해당 행의 `deleted` 칸을 `TRUE` 로
- 행을 통째로 지워도 된다
